# GSE42693 revision audit and bounded reanalysis

Recorded 2026-10-11 before executing the stage31 statistical script. Earlier stage15/stage28 results are already known. This is a verification of an existing exploratory analysis, not a preregistered experiment or independent validation. The additional measurable-family BH analysis below is a new, explicitly secondary sensitivity.

1. Read the unchanged deposited GSE42693 series matrix, GPL1355 annotation dated 2016-08-09, fixed 25 human candidates and archived Ensembl 116 orthology/Entrez cross-reference. Hash all input files before and after execution. Do not change a source input, candidate threshold, annotation version, sample or probe according to an effect.
2. Verify the deposited value scale using its embedded processing metadata, full distribution and individual probe values. Read the original Ide et al. 2009 Methods. Distinguish the deposited GCOS 1.4 globally scaled signal from the original paper's subsequent GeneSpring percentile/per-gene normalization. Do not describe deposited values as raw CEL, RNA counts, RMA or an already-log-transformed matrix. If evidence contradicts this interpretation, stop the transformation-dependent calculation and document it.
3. Primary animals are the five control GSM1048036–GSM1048040 and five sesamin GSM1048041–GSM1048045. Retain all 20 arrays for source diagnostics and the existing quantile-normalization sensitivity. Episesamin and sesamolin are distinct exposures, never additional sesamin replicates. The source paper selected five of seven rats per group by excluding terminal-body-weight extremes; this reanalysis does not undo that selection.
4. Rebuild the mapping for all 25 fixed human IDs from archived Ensembl 116, requiring exactly one one-to-one rat orthologue and one Entrez identifier. Keep GPL1355 probes with one unique deposited Entrez ID matching that target; save excluded matching probes and all mapping decisions. No effect-based probe selection or sequence-level remapping. Preserve unavailable candidates as NA. List symbols and identifiers separately because names can change between the annotation and orthology versions.
5. Primary scale is log2(deposited signal + 1). Calculate each animal's median across all eligible probes after transformation; if all candidates have a single probe, state that the multi-probe rule has no effect here. Existing sensitivity applies deterministic quantile normalization to all 31,099 probes on all 20 log-transformed arrays, averaging target ranks across ties, before the same aggregation. Keep the complete feature background and every animal.
6. For both scales and every mapped candidate, compute sesamin minus control mean, SDs, nominal two-sided 95% Welch interval, Welch t statistic/degrees of freedom/two-sided P, and an exact-label reference P from all 252 choices of five of ten animals. The exact statistic is the absolute difference in means; include the observed allocation and ties with absolute tolerance 1e-12. It assumes exchangeability under the null and is not a verified randomized causal test. Neither test corrects the original body-weight selection; normal-model approximations, discrete exact tails and design limitations remain visible.
7. Primary multiplicity correction remains BH over 25 hypotheses. Unavailable P values contribute 1 only inside the adjustment, while their reported P and adjusted P stay NA. As a new secondary sensitivity, also report BH over the measurable candidates with finite P values. Label this BH_measurable and never replace BH25 or interpret it as the originally fixed family. Do not use this sensitivity to select results.
8. Save all animal-level and probe-level values, both normalization methods, both tests, all 25 hypotheses including NA, input and environment versions, old/new numerical differences, and complete checks. Compare numerical differences to saved values using their stored precision; do not adjust calculations to reproduce rounded prose.
9. Checks include matrix and annotation uniqueness, all 25 candidate identities, all 20 animal identities, reconstructed mapping equivalence, SciPy/manual Welch agreement, exact enumeration count/parity, BH checks against SciPy, NA preservation, positive VNN1 direction evaluation without using it as a requirement, and source input hash preservation. Any mismatch is reported; only structural and mathematical invariants are asserted.
10. Outputs are restricted to this rat_analysis directory. No source-data reprocessing from CEL files, new animal experiment, fresh annotation release, software installation, external upload or journal submission is performed.
