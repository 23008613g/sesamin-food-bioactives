# Historical scientific source

These are the earlier candidate-selection, PHH, mouse quantification, organoid extraction, independent-check and figure-generation scripts. They are included so the repository covers the research code beyond the later processed-input reproduction subset.

They require the original directory layout, scientific inputs and, where applicable, external tools. Paths/contact strings were redacted in distributed copies; the original hashes and distributed hashes are recorded. `<WORKSPACE>` and `<LOCAL_PATH>` are archival placeholders, not working defaults. No source algorithm was rewritten to claim a new end-to-end reproduction.

Do not invoke historical setup/download scripts merely to reproduce the current main figures. Use the portable paths documented in the root README. Raw acquisition and expensive reanalysis were not run during repository preparation. Dependency environments for these older scripts were not freshly installed or independently retested.

Some historical figure scripts refer to the earlier separately installed figure QA helper. That helper is not vendored. Current main-figure code uses a small project-local geometry check with a narrower documented scope.
